# Dogs Store — Mini App Web

واجهة متجر Dogs Store (Telegram Mini App) مجمّعة من ملفات المشروع الأصلية
(`MINIAPP_HTML` داخل ملف البوت + `miniapp_design.css` + `reseller_mini_v12.js`)
بنفس طريقة ما البوت بيقدّمها بالظبط، بثيم Panda Store بهوية Dogs Store:
ألوان أحمر / أسود / دهبي ولوجو كلب مافيا.

## الملفات

- `index.html` — النسخة المجمّعة الكاملة (التصميم والـ JS مدمجين جواها زي نسخة البوت).
  دي اللي بتتفتح من GitHub Pages.
- `demo.html` — نفس الصفحة + طبقة بيانات تجريبية محلية، لعرض التصميم فقط.
  البيانات الحقيقية في التشغيل الفعلي بتيجي من API البوت.
- `miniapp_design.css` — ملف التصميم منفصل (نفس اللي بيتحط جنب البوت على السيرفر).
- `reseller_mini_v12.js` — إضافة الريسيلر/API (مدمجة برضه جوه index.html).
- `logo.png` — لوجو Dogs Store (بيظهر في شاشة البداية).

## ملحوظة

الواجهة لوحدها لا تكفي للتشغيل التجاري: الشراء والرصيد والطلبات بتتم عبر
API البوت (`/api/...`) اللي بيقدّمه ملف البوت على سيرفره.
